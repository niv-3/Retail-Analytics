# Retail Analytics

An end-to-end retail analytics project exploring e-commerce performance using Python, PostgreSQL, SQL, and Power BI.

The project uses the Olist e-commerce dataset to transform raw transactional data into business-focused analysis and insights.

## Project Objective

The goal of this project is to analyze retail data and answer practical business questions around sales performance, customers, products, sellers, payments, and delivery.

Key questions explored include:

- How does revenue change over time?
- Which products and categories contribute most to performance?
- How do sellers perform?
- Where are customers located?
- What payment methods do customers prefer?
- How does delivery performance affect the customer experience?
- What patterns can be identified across different customer segments?

## Analytics Workflow

The project follows an end-to-end analytics workflow:

1. Explore and understand the raw Olist datasets.
2. Inspect data quality, structure, and relationships.
3. Clean and prepare data using Python and pandas.
4. Load and organize data for relational analysis.
5. Query the data using PostgreSQL and SQL.
6. Calculate business metrics and investigate retail performance.
7. Visualize results and communicate insights using Power BI.

## Analysis Areas

The analysis focuses on several areas of retail performance:

### Sales & Revenue
Analysis of revenue patterns and changes over time.

### Products
Investigation of product and category performance.

### Customers
Analysis of customer behavior, location, and purchasing patterns.

### Sellers
Evaluation of seller activity and performance.

### Payments
Exploration of customer payment preferences and transaction behavior.

### Delivery
Analysis of delivery performance and its relationship with the customer experience.
